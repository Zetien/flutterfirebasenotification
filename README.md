# push_notificacion_app
this an small app to use firebase notifications.


## Steps

 - First, you need configure your firebase account and conect your account with this app to make work!! you need create a single project there...
 - Two, you need configure the FlutterFire with the CLI in order to list the firebase projects, search your proyect by the Id
 - Three, read the documentation flutterFire CLI config if does no work
